<details>
<summary><strong>Click here for the developer setup guide</strong></summary>
<br>

1.  **Fork & Clone the repository:**
    ```sh
    git clone [https://github.com/YOUR_USERNAME/wisk.git](https://github.com/YOUR_USERNAME/wisk.git)
    cd wisk
    ```
2.  **Install dependencies:**
    ```sh
    # Using npm
    npm install

    # Or using Yarn
    yarn install
    ```
3.  **Configure API Keys:**
    -   In the `app.json` file, locate the `extra` section.
    -   Add your Google Gemini and Vision API keys there. Your keys are safe and are not exposed in the build.
    ```json
    "extra": {
      "GEMINI_API_KEY": "YOUR_GEMINI_KEY_HERE",
      "VISION_API_KEY": "YOUR_VISION_KEY_HERE"
    }
    ```
4.  **Launch the App:**
    ```sh
    npx expo start
    ```
    Scan the QR code with the Expo Go app on your phone, or run it in an emulator. It's that easy!

</details>
